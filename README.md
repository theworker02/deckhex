# deckhex

Deck filesystem hex paths across POSIX and Windows conventions.

**Site:** https://theworker02.github.io/deckhex/

## Install / run

```bash
git clone https://github.com/theworker02/deckhex.git
cd deckhex
node src/cli.js
node --test
```
